## 文章内 HTTP 服务验证

临时启动从第 17 篇提取的 `Demo17 serve`，请求本机 127.0.0.1:8080。服务直接访问 H2 数据库，不是返回固定字符串的替身。验证结束后已停止服务。

| 请求 | 结果 |
| --- | --- |
| GET /users?id=7 | 200，Lin |
| POST /rename?id=7&name=Grace | 200，renamed |
| 再次 GET /users?id=7 | 200，Grace |
| POST /rename-fail?id=7&name=Bad | 500，controller failed |
| 失败后再次查询 | 仍为 Grace，证明回滚生效 |
| GET /users?id=bad | 400 |
| GET /missing | 404 |
| POST /users?id=7 | 405，Allow 为 GET |
| GET /users?id=7&id=8 | 400，重复参数被拒绝 |
| 更新姓名为中文后查询 | 200，正确返回中文 |

同时检查响应 Content-Length 与实际 UTF-8 字节数一致。
