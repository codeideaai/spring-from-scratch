## 可重复执行的命令

```bash
python3 tools/format_java.py check
python3 tools/verify_article_code.py
bash examples/library/run.sh test
python3 tools/verify_library_restart.py
```

先按首页命令准备 JDK 17 和 H2 驱动。Spotless 3.10.3 使用 google-java-format 1.24.0 的 GOOGLE 风格，共检查 48 份 Java 文件：34 份文章程序与项目中的 14 份源文件。中英文注释分别撰写，可执行词法单元和预期输出逐对校验。项目一致性检查另核对 83 处共享组件快照，覆盖全部 14 份项目源文件；明确保留三个较早教学阶段的差异。

独立项目验收检查正常提交、重复编号、同书同读者重复、写入间异常、线程连接清理、嵌套拒绝、库存竞争、HTTP 和启动失败资源清理。进程重启脚本使用临时文件数据库，启动两个先后独立的 Java 进程，确认第二次启动库存没有重置、已有读者仍不能重复预约。

## HTTP 验收约定

| 情形 | 结果 |
| --- | --- |
| 查询存在图书 | 200 |
| 合法预约 | 201，库存减少且有对应记录 |
| 重复读者或编号 | 409，库存恢复 |
| 缺失参数、非法数字、重复 Query 参数 | 400 |
| 不存在图书或路径 | 404 |
| GET /reservations | 405，Allow 为 POST |
| 扣库存后注入故障 | 路由返回 500，两张表状态不变 |
| 中文读者名称 | UTF-8 正确返回，Content-Length 等于实际字节数 |

故障钩子由测试构造应用时注入，不是公开的 HTTP 接口。HTTP、H2 并发和启动清理的成功不等于生产可用性；支持范围以[实现边界](实现边界与延伸阅读.md)为准。
